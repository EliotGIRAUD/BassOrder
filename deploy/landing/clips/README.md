# Audio clips — Live Preview (landing)

Drop here **4 to 8** audio files you have the right to publish (your tracks, free versions, short excerpts).

## Steps

1. Put the files in this folder, e.g.:
   - `01-chillax-a.mp3`
   - `02-chillax-b.mp3`
2. Edit `clips.json`: title, artist, folder/genre, file name.
3. Redeploy on the VPS (`/var/www/bassorder/clips/`).

OK formats: `.mp3`, `.m4a`, `.ogg`, `.wav` (MP3 recommended).

Titles listed in `clips.json` appear in the scan demo with a **listen** badge; a click opens Live Preview (like in the app).

Placeholder entries `Remplace-moi` / `01-extrait.mp3` are examples: replace them with your real files.
