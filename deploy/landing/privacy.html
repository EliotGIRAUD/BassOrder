Politique de confidentialité

Dernière mise à jour · 21 août 2026

BassOrder est une application desktop open source qui aide à trier de la musique par genres musicaux (Spotify et fichiers locaux). Cette page explique quelles données sont traitées, où elles restent, et quels sont tes droits.

1. Responsable

Le traitement lié au site bassorder.smegg.cloud et à l’API optionnelle api.bassorder.smegg.cloud est assuré par Eliot GIRAUD (projet personnel / open source). Contact pour les demandes vie privée : issues GitHub (objet « Privacy ») ou advisory sécurité décrit dans SECURITY.md.

2. Principes

  • Local d’abord : bibliothèque, tags, historique et profils locaux restent sur ta machine (SQLite).
  • Pas de publicité / pas de vente de données.
  • Pas de télémétrie marketing dans l’app (pas d’outil d’analytics type Google Analytics sur la landing à ce jour).
  • Le cloud (compte email + sync « knowledge ») est optionnel.

3. Données traitées

3.1 Sur ton appareil

  • Pseudo / couleur de profil local
  • Métadonnées musicales (artistes, titres, genres proposés / validés), chemins de dossiers que tu choisis
  • Jetons Spotify (OAuth) stockés localement pour appeler l’API Spotify en ton nom
  • PIN / préférences locales si tu les actives

Les fichiers audio ne sont pas uploadés vers nos serveurs : copie / déplacement se fait sur ton disque.

3.2 Compte cloud (optionnel)

  • Adresse e-mail
  • Mot de passe (stocké sous forme de hash Argon2id, jamais en clair)
  • Jetons JWT / refresh pour la session
  • « Knowledge » synchronisé : associations artiste ↔ genre (miroir privé et, si tu participes, contributions à un pool agrégé)

Base légale : exécution du service que tu demandes (compte + sync) et, pour le pool agrégé, ton consentement / usage volontaire de la fonction.

3.3 Site web

  • Logs techniques du serveur web / reverse-proxy (IP, user-agent, URL) pour sécurité et diagnostic — conservation limitée
  • Téléchargement des installateurs (pas de compte requis)

4. Spotify

Si tu connectes Spotify, le traitement des données Spotify est aussi régi par les règles de confidentialité Spotify et les conditions développeur Spotify. BassOrder n’est pas affilié à Spotify AB. Tu peux révoquer l’accès dans les paramètres de ton compte Spotify.

5. Destinataires & hébergement

  • Données locales : uniquement toi (et les programmes que tu autorises sur ta machine)
  • API / site : hébergement VPS (domaine smegg.cloud) — accès réservé à l’administration du projet
  • Code source public : GitHub (pas tes données personnelles d’usage)

Pas de revente à des brokers. Pas de sous-traitants marketing. Les prestataires d’infra (hébergeur, certificats TLS) peuvent voir des métadonnées techniques inhérentes à Internet.

6. Durées de conservation

  • Local : tant que tu gardes l’app / la base SQLite
  • Compte cloud : jusqu’à suppression du compte ou demande d’effacement
  • Logs serveur : durée courte, besoins sécurité / exploitation

7. Sécurité

HTTPS, mots de passe hashés, rate-limit sur l’auth, principe du moindre privilège sur le serveur. Aucun système n’est infaillible : signale une faille via SECURITY.md.

8. Tes droits (RGPD)

Selon le droit applicable (UE / France), tu peux demander :

  • accès, rectification, effacement
  • limitation ou opposition
  • portabilité des données que tu as fournies (ex. email / knowledge)
  • retrait du consentement pour les usages optionnels

Pour exercer ces droits : ouvre une issue « Privacy » sur le dépôt ou contacte le mainteneur. Tu peux aussi introduire une réclamation auprès de la CNIL.

9. Mineurs

Le service n’est pas destiné aux enfants de moins de 15 ans (ou âge local équivalent). Ne crée pas de compte cloud si tu n’as pas l’âge requis.

10. Modifications

Cette politique peut évoluer avec le projet. La date en tête de page fait foi. Pour les changements importants, une note pourra être ajoutée sur le site ou le dépôt.

Cette politique s’applique uniquement au service BassOrder exploité par l’éditeur à l’adresse indiquée ci-dessus. Toute redistribution du logiciel, toute instance auto-hébergée ou tout service tiers basé sur BassOrder relèvent de la seule responsabilité de la personne qui les exploite, y compris au regard de la réglementation applicable aux données personnelles.
